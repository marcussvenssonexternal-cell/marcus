# Agents need something to read

_AI strategy · for CTOs, CPOs and innovation leads, Tier-1 streamers, Broadcasters, Telco / cable operators_

**Every vendor shipped an agent this autumn. An agent is only as good as what it can read about the content. Grounding in facts fixes a made-up cast list, but a request like 'tense but not violent, under 100 minutes' needs to know how the scenes feel.**

## Why now

At least 13 of the companies the radar tracks pitched agents at or since IBC, from Gracenote's MCP server and entertainment SLM to ThinkAnalytics and ContentWise putting agents into editorial tools. Ad buying is going agentic too (Magnite's orchestration layer), and those agents will read structured content data. The question for buyers has moved from 'do you have an agent?' to 'what does it understand?'.

## Questions the series answers

- What does an agent actually need to know about a title to act on it?
- Where do media agents fail today: invented metadata, generic answers, no sense of tone?
- What is an MCP server, in plain words, and why should a catalogue owner care?
- Who should own the understanding layer: the platform, the vendor or the agent?
- How do you test an agent on your own catalogue before you buy it?
